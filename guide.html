Document Routing Specification

Guidelines for automated content indexing and deployment via filename parsing.

1. Routing Mechanism

The system utilizes a static parsing engine to automatically categorize and route documents based on reserved keywords present in the filename. By adhering to the standard naming convention, files are indexed into the correct directories without requiring manual configuration.

Standard Convention

[Class] [Semester] [Subject] [Description].pdf

2. Reserved Keywords Reference

Acceptable parameters for document classification.

Category Acceptable Keywords Default (If Omitted)
Class Level Class 11, Class 12 General
Semester Sem 1, Sem 2, Sem 3, Sem 4 General Resources
Subject COMS, COMA Others
Document Type (Optional Badge) Syllabus, Notes, PYQ / Question, Book No Badge

3. Multi-Node Routing Patterns

Multiple keywords from the same primary category can be combined within a single filename. The parsing engine executes a cross-product generation, indexing the document across all specified directories simultaneously.

Cross-Semester Indexing

Distributes a single file to Semesters 1 and 2.

Class 11 Sem 1 Sem 2 COMS Networking.pdf

Mapped to: Class 11 > Sem 1, Class 11 > Sem 2

Cross-Class Indexing

Distributes a single file to Classes 11 and 12.

Class 11 Class 12 Sem 3 COMA Logic.pdf

Mapped to: Class 11 > Sem 3, Class 12 > Sem 3

4. Deployment Pipeline

This project is configured with a GitHub Actions Continuous Integration (CI) pipeline. Adding or modifying files within the repository automatically triggers an index rebuild and deploys updates to production.

  1. Access the repository via the GitHub web interface and navigate to the pdfs/ directory.
  2. Select Add file > Upload files and upload the properly formatted document.
  3. Select Commit changes to finalize the upload.

Note: The CI pipeline executes asynchronously. Please allow 15-30 seconds for changes to reflect on the live environment.
