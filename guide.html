PDF Naming Guide 📄

Learn how to name your PDFs so they automatically appear in the correct Class, Semester, and Subject sections on the website.

✨ The Magic is in the Name!

You don't need to be a programmer to organize your PDFs. The website is smart enough to know where to put a file just by looking at its name.

Example of a good name:

Class 11 Sem 1 COMS Notes.pdf

Because you wrote "Class 11", "Sem 1", and "COMS" in the name, the website will automatically put it exactly where students expect to find it!

🏫 What Class is it for?

Just type one of these anywhere in the file name:

  • • Class 11
  • • Class 12

📅 What Semester?

Include one of these in the name:

  • • Sem 1
  • • Sem 2
  • • Sem 3
  • • Sem 4

📚 Which Subject?

Type the short name of the subject:

  • • COMS (for Computer Science)
  • • COMA (for Computer Application)

🚀 Pro Tip: Putting one file in multiple places

What if you have a PDF that is useful for both Semester 1 AND Semester 2?
Just put both words in the file name!

If you name your file:

Class 11 Sem 1 Sem 2 COMS Guide.pdf

The website will be smart enough to show it in both Semester 1 AND Semester 2!

One Last Step: Tell the website it's there!

Even though the website sorts things for you, it still needs to know the file exists.

  1. Drop your newly named PDF into the pdfs folder.
  2. Go to your main website folder and double-click the file named Update_Website.command.
  3. A black terminal window will pop up, do its magic instantly, and tell you it's done. You can close it!
  4. Refresh your website. Your PDF will be there!
